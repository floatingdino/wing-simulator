## Log
- 2026-10-25 coordinator: created by decomposing epics T040-T044/T051 after T004.

- 2026-10-25 T04G/T04H agent (shared branch `task/T04G-T04H`): **done, ready for review.**
  - Approach: no fitting. Each model is a line-by-line port of WING-Edit 3.3.4's `ae::eq_parchg_<model>`
    (arm64 disassembly) plus the `Cbiquad` primitives it calls (`hqpeq` Orfanidis bell, `ls12q2`/`hs12q2`
    shelves, inline 1st-order shelves, PULSAR's `bilin_z_trans_2_par`), with the editor's static tables extracted
    verbatim (`tables.rs`, generated by `tools/curve-extract/eq_alt_tables.py`). float32/fma/double ops mirrored.
    T03C's `wingcoef` (merged mid-task) covers the STD-EQ primitives (`peq` = `hqpeq`) but not `ls12q2/hs12q2`
    or the model code; the eq_alt `prims` were already verified 0-ulp, so they were kept (possible later dedup).
  - Files: `crates/wing-blocks/src/models/eq_alt/{mod,prims,tables,soul,e88,e84,f110,pulsar,mach4,pia,tests}.rs`,
    `crates/wing-blocks/benches/eq_alt.rs` (+ Cargo.toml entry), `models/mod.rs` (`pub mod eq_alt`), `model.rs`
    (7 factory lines + EQ stub test flipped), `fidelity.rs` (stub test now uses an FX stub),
    `tools/curve-extract/eq_alt_{oracle,jobs,tables}.py` (emulator oracle + table generator).
  - Fidelity vs `data/reference-curves/eq-<model>.json` (all curves, replaying the extractor's carried-over state
    in file order, e.g. E84's HF grid ran with LF=220): max |err| SOUL 0.0005, E88 0.0005, E84 0.0006,
    F110 0.0005, PULSAR 0.0005, MACH4 0.0005, PIA 0.0007 dB (= the 0.001 dB rounding of `mag_db`).
    Extra oracle (emulated WING-Edit, 300 random settings/model incl. enums, plus a run with random mix 0..125 %):
    coefficients bit-exact (0.000000 dB; SOUL 0.00003 dB with mix), all three primitives 0 ulp.
    Audio path (f64 TDF-II, MACH4 parallel) matches the design < 0.01 dB at 48 and 44.1 kHz (test).
  - Runtime: 20 ms knob glides with redesign every 16 samples + per-sample coefficient ramps; enum/switch changes
    crossfade 10 ms; no allocation after construction. Bench (M-series, 64-sample stereo): ~0.54 us/block static
    (PIA 0.83 us), 1.2-2.8 us under continuous automation.
  - Nonlinear colour: none added. WING-Edit's EQ code is purely linear biquads and models.md gives no evidence of
    transformer/tube emulation in WING's EQs (PULSAR/E84 colour of the hardware is not modelled by WING-Edit).
  - Test: `make check`; dev oracle: `WING_EQ_ALT_ORACLE=<json> cargo test -p wing-blocks oracle -- --nocapture`.
  - Proposed follow-ups: (1) WING-Edit passes `mix/100` into every parchg as a *gain scale* (125 % = exaggerated
    EQ), not dry/wet; `AltEq::set_gain_scale` implements it but ModelSlot still does dry/wet for EQs.
    (2) 44.1 kHz table variants (PULSAR HF att, PIA HF, MACH4) are ported but not oracle-checked at 44.1 kHz.
    (3) WING-Edit quirk kept: PULSAR mid-dip mix ratio divides the low-boost value (stale register).
    (4) Dedup `prims::hqpeq` with `wingcoef::peq` once both are cross-checked bit-exact.
